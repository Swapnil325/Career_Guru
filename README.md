# Career Guru 🎓

An Android career guidance app that helps students explore career paths across various domains after 10th and 12th grade.

## Features

- **After 10th** – Explore ITI, Diploma, and vocational options
- **After 12th** – Browse streams: Science, Commerce, Arts, and course options (BA, B.Com, BCS, Law, Pharmacy, Architecture)
- **Graduation** – MBA, M.Tech, Data Science, Digital Marketing, CA, HR Manager, Business Analyst
- **Competitive Exams** – UPSC, MPSC, SSC CGL, NDA, CDS, Railway, Defence
- **Short-Term Courses** – Tally, MSCIT, Graphics, Animation, Web Design, Cyber Security
- **Vocational Courses** – Agriculture, Dance, Music, Journalism, Textile Design, eCommerce
- **Paramedical** – OT, DLMT, DOA, DOT, DHFM, Health Inspector
- **Sports** – Cricket, Football, Hockey, Badminton, Athletics, Kabaddi
- **ESports** – Game Design, Event Manager, Esports Producer, Community Manager, Marketing Executive, Product Manager
- **Social Media Influencer** – Content Creation, Instagram, Collaboration, Local SEO, Content Marketing, Monitoring
- **Share Market** – Stock Broker, Trader, Financial Analyst, Investment Banker, Portfolio Manager, Research Analyst

## Tech Stack

- **Platform:** Android (Java)
- **Backend:** Firebase (Authentication & Database)
- **Min SDK:** Android 5.0+
- **Build Tool:** Gradle

## Project Structure

```
app/src/main/
├── java/com/example/career_explorer/   # Activity classes
├── res/
│   ├── layout/                         # XML layouts
│   ├── drawable/                       # Images and icons
│   └── values/                         # Strings, colors, themes
└── AndroidManifest.xml
```

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/<your-username>/Career_Guru.git
   ```
2. Open the project in **Android Studio**
3. Add your `google-services.json` file in the `app/` directory (Firebase config)
4. Build and run on an emulator or physical device

## Requirements

- Android Studio Flamingo or later
- JDK 11+
- Google Firebase project with Authentication enabled
